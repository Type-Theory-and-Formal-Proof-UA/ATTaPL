# Поглиблені теми з типів та мов програмування (переклад)

Український переклад книжки *Advanced Topics in Types and Programming
Languages* (за редакцією Benjamin C. Pierce, The MIT Press, 2004), набраний у
[Typst](https://typst.app/).

**Читати онлайн:** <https://type-theory-and-formal-proof-ua.github.io/ATTaPL/>
(HTML по розділах і PDF).

## Стан перекладу

Перекладено розділи 1–10:

| Розділ | Назва |
| --- | --- |
| 1 | Субструктурні системи типів |
| 2 | Залежні типи |
| 3 | Типи ефектів і керування пам’яттю на основі регіонів |
| 4 | Типізована мова асемблера |
| 5 | Код, що несе доведення |
| 6 | Логічні відношення та приклад дослідження перевірки еквівалентності |
| 7 | Типізоване операційне міркування |
| 8 | Міркування про проєкт модульних систем у стилі ML |
| 9 | Означення типів |
| 10 | Сутність виведення типів ML |

Додаток A (розв’язки вибраних вправ), бібліографію та покажчик перекладено й
додано до збірки.

## Структура

```
book/attapl-uk.typ     точка входу: складає всю книжку
book/chNN.typ          розділ NN = включення його частин з out/
out/<частина>/uk.typ   переклад однієї частини розділу
templates/preamble.typ спільна преамбула: заголовки, середовища тверджень
                       (Lemma, Theorem, Exercise…), блоки правил виведення
templates/html.typ     правила показу для HTML-експорту
templates/frontmatter.typ титульна сторінка
tools/split_html.py    розрізає HTML-експорт Typst на сторінки по розділах
```

Текст оригіналу та PDF книжки не розповсюджуються (авторське право): у
репозиторії лише переклад і засоби збирання.

## Збирання

Потрібен [Typst](https://github.com/typst/typst) 0.15 (`brew install typst`)
і Python 3.

```sh
make build   # PDF: attapl-uk.pdf
make html    # HTML по розділах і PDF: site/
```

## Публікація

`.github/workflows/deploy.yml` на кожен push до `main` збирає HTML-видання
(`typst compile --features html --format html`, експорт у Typst ще
експериментальний; формули виходять як MathML, а правила виведення й таблиці —
як вбудований SVG) та PDF і розгортає їх на GitHub Pages.
